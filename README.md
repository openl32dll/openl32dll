## 🚀 Öne çıkan proje

### [`cs2-discord-rpc`](https://github.com/openl32dll/cs2-discord-rpc)
Counter-Strike 2 oynarken Discord profilinde sadece "oynuyor" yazısı yerine
**hangi haritada**, **hangi modda** (Rekabetçi/Premier, Wingman, Casual,
Deathmatch, Arms Race, Demolition...) ve **kaçıncı roundda** olduğunu
gösteren bir araç.

- Valve'ın **Game State Integration (GSI)** API'sini kullanıyor, yerel bir
  HTTP sunucusu ile veriyi okuyup `pypresence` üzerinden Discord'a iletiyor.
- Harita başına özel rozet görselleri, ekran görüntüsü içe aktarma aracı,
  Windows'ta oturum açılışında otomatik başlatma desteği içeriyor.
- Kod tabanı tip anotasyonlu, tek dosyalık ve okunaklı; kurulumdan mod
  eşlemesine kadar her adım README'sinde belgelenmiş.
